# Lore brand system

Lore should feel like a calm technical archive: precise enough for engineers, editorial enough to make institutional memory tangible.

## Positioning

**Lore — engineering memory your agents can prove.**

Supporting line: **The evidence-backed context and governance layer around AI coding agents.**

## Visual language

- Deep ink `#071522` anchors navigation and trusted infrastructure.
- Coral `#f04e3e` marks primary decisions and active selection.
- Teal `#0b8f72` means supported/healthy; brass `#c98612` means caution; red `#dc3e43` means blocked.
- The main canvas is true white, with cool slate text and hairline borders.
- The mark uses stacked evidence layers that also suggest an open book and a connected graph.
- UI typography is compact and clear; monospace is reserved for symbols, paths, and evidence IDs.

The dashboard and candidate-review design specifications are stored in `docs/design/`.
